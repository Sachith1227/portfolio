# Chamalka Senavirathna — Portfolio

A local-first developer portfolio built with React, TypeScript, and Vite. The page currently contains the header and hero, ending with the portrait and CS watermark. All sections below the portrait and the footer are removed from the page; their source and assets are retained for later restoration. Reduced-motion preferences and the saved animation toggle are supported.

## Run locally

```sh
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` if execution policy blocks `npm.ps1`.

```sh
npm run build
npm run preview
```

## Project structure

```text
src/
  App.tsx                    Page composition
  main.tsx                   React entry point and stylesheet imports
  components/                Shared UI: header, footer, icons, project cards
  sections/                  Hero; retained About, Projects, Stack, Connect, Milestones
  hooks/                     Scroll effects and saved motion preference
  data/portfolio.ts          Navigation, projects, technologies, milestones
  styles/
    global.css               Font imports, resets, accessibility defaults
    portfolio.css            Base layouts, components, and animations
    responsive.css           Layout changes for screen sizes
    theme.css                Colors, display typography, and interaction styling
public/
  chamalka-portrait.png       Portrait image
  favicon.svg                CS monogram
  projects/                  Project screenshots and artwork
```

Edit a file in `src/sections/` to change a page section. Edit
`src/data/portfolio.ts` to update project content and links. The name appears in
`src/sections/Hero.tsx`, and the shared monogram is in `src/components/Brand.tsx`.

Styles load in the order shown above; `theme.css` contains the final appearance
settings. Build output in `dist/` is generated by Vite and should not be edited.

To restore a section, import and render it after `Hero` in `App.tsx`. The retained
`Footer` component can be restored after `main`. Header section navigation has
been removed because only the hero remains.
Render `Milestones` from `src/sections/Milestones.tsx` at the end of `About.tsx`
to restore the timeline. The hero's "View projects" link currently opens GitHub
repositories.

## Checks and formatting

```sh
npm run build
npm run format
npm run format:check
```

Prettier formats the source using `.prettierrc.json`. Build output, dependencies,
and the lockfile are excluded from formatting. Keep `package-lock.json` and the
TypeScript/Vite configuration files; they are required for reproducible builds.
