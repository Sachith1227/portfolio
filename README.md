# Chamalka Senavirathna — Portfolio

A local-first developer portfolio built with React, TypeScript, and Vite. It includes a responsive project showcase, category filters, an interactive terminal, scroll reveals, a mobile menu, and a persistent animation toggle. Reduced-motion preferences are respected.

## Run locally

```sh
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` if execution policy blocks `npm.ps1`.

```sh
npm run build
npm run preview
```

## Edit content

- `src/data.ts`: featured project descriptions, source links, technologies, and journey milestones.
- `src/App.tsx`: layout, biography, terminal, and interactions.
- `src/App.css` and `src/index.css`: styling and animations.
- `public/chamalka-portrait.png`: the current portrait, with transparent background.
- `public/projects/`: screenshot and artwork from the public project repositories.

Terminal commands: `help`, `whoami`, `about`, `projects`, `stack`, `github`, and `clear`. This is a browser-local portfolio terminal, not a shell.
